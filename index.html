❓ Perguntas Frequentes

O SpecView é gratuito? ▼
Sim! O SpecView é completamente gratuito para uso pessoal. Há uma versão Pro com recursos avançados como relatórios detalhados e alertas customizados disponível por assinatura mensal.
O SpecView é compatível com Windows 10? ▼
Sim! O SpecView é compatível com Windows 10 (64-bit) e Windows 11. Recomendamos manter o Windows atualizado para melhor compatibilidade com os sensores de hardware.
Como faço para reportar um arquivo suspeito? ▼
Você pode reportar arquivos suspeitos através do botão "Reportar" em cada download, ou enviando um e-mail para seguranca@mzapps.com. Nossa equipe analisa todos os relatórios em até 2 horas.
Como atualizo o SpecView? ▼
O SpecView possui atualização automática. Você receberá uma notificação quando uma nova versão estiver disponível, e pode atualizar com um clique. Também é possível baixar a versão mais recente diretamente no nosso site.
Posso usar o SpecView em mais de um PC? ▼
Na versão gratuita, sim — sem limitações de instalações. Na versão Pro, você pode usar em até 3 dispositivos com uma única licença.
